# SZPU-China 2026 Wiki (Frozen-Flask)

This folder is the **official iGEM 2026 wiki source** for `gitlab.igem.org/2026/szpu-china`.
It follows the iGEM-provided `wiki-frozen-flask` template: a Flask app is frozen into a
static site by `flask freeze` and published by GitLab Pages.

## 本目录的定位：GitLab 站的镜像（2026-10-16 明确，勿忘）

**为什么有这个 flask 站。** 仓库根目录的根站（Nunjucks + 静态站）是我们自己的开发站，评委看不到它；
`igem2026-flask/` 是**对标 GitLab 站的那一份**。所以工作流是单向的：

```
根站（根目录，开发与设计基准）
  └─ 复刻 → igem2026-flask/（本地预览、验收；目录结构 = GitLab 仓库结构）
       └─ 整体复制同步 → GitLab 仓库 gitlab.igem.org/2026/szpu-china
            └─ CI `flask freeze` → 发布 2026.igem.wiki/szpu-china（评委看到的线上站）
```

由此推出三条判定口径，改任何文件前先对照：

1. **同名同路径**：这里的目录结构就是 GitLab 仓库结构，除了下面「绝不拷贝」清单，可以整目录复制过去；
2. **内容以根站为准**：页面文案/结构与根站逐字节对齐（图片一律走 CDN，所以图片路径写法与根站不同，这是唯一的预期差异）；
3. **验收标准不是「本地能跑」**，而是「复制过去后线上与根站一致」——本地预览只是中间检查点。

### 页面口径：以根站为准；根站没有的页面，绝不覆盖线上（2026-10-16 定为红线）

- **判定标准**：根站（仓库根目录的静态站）**有**这个页面 → 它是我们要做的页面，本地版可以推上去；根站**没有**这个页面 → 说明我方不参与该奖项/模块，**不得把本地占位版推上去覆盖线上那一页**。
- **已确认不参与、仓库里必须保持与线上逐字节一致（用 `git checkout igem/main -- <path>` 还原）的页面**：
  `wiki/pages/inclusivity.html`、`wiki/pages/measurement.html`、`wiki/pages/entrepreneurship.html`。
- **绝不删这些文件**：推送树 = 仓库全量状态，缺一个路径等于**删除线上页面**（评委可能正好访问它）。正确做法是让它与 `igem/main` 一致，从而自然退出推送清单。
- 以后新增页面先问一句「根站有没有」；没有就别把占位版做进推送包，也不要给它们做导航入口。
- 背景：`inclusivity`（线上 2321 B，官方模板页）、`measurement`（2107 B）、`entrepreneurship`（1411 B）三页，本地曾各有一份占位版（378 / 947 / 853 B）并已进了推送包，2026-10-16 分别在 r16 / r17 还原为线上版（包体 382 → 381 → 379）。

## Compliance notes

- **Rule 1 (hosted on iGEM):** all CSS/JS are vendored under `static/` and served by
  GitLab Pages (iGEM infrastructure). No third-party CDNs (Google Fonts, jsDelivr,
  alicdn, …) are referenced. The only external hosts are `static.igem.org` (favicon,
  an iGEM domain) and allowed outbound links (szpu.edu.cn, bilibili, mailto).
- **Rule 2 (CI build):** GitLab CI runs `flask freeze` on the default branch and publishes
  `public/` via GitLab Pages (see `.gitlab-ci.yml` in the repo root).
- **Rule 3 (predictable URL + footer link):** every page has a clean, predictable URL
  (`/Description`, `/Model`, …) and the footer contains a visible
  `gitlab.igem.org/2026/szpu-china` link plus the CC BY 4.0 license.
- **JS placement:** no `<script>` tags appear inside page templates; all JS is loaded
  once from `layout.html` (Bootstrap bundle, vendored locally).
- **Bootstrap:** the layout uses Bootstrap 5, vendored locally under `static/bootstrap/`.

## 迁移前必做：页面与组件清洁整理（所有 agent 通用，2026-10-20 立规）

**任何"把本地文件推去 GitLab"的动作，第一步不是拷文件，而是清洁整理。** 历史事故（2026-10-11/12、10-19）都是"没清就推"，导致 CI 连红、线上与本地不一致。按下面顺序做完，才能进 `flask freeze`。

### 0. 判定口径：哪些能动、哪些绝对不动

- **根站（仓库根目录静态站）没有的页面 = 我们不参与**：本地占位版不得推送，也不得加导航入口（见上文「页面口径」）。
- **官方模板自带的资源，零引用也不删**：`static/js/3dmol/3Dmol-2.0.1-min.js`、`static/js/reports-lib/*`（bootstrap / chart）在远端树里存在，删了等于删官方资源。孤儿扫描必须区分「本地遗留」与「官方自带」。
- `static/image/`（176 MB）、`static/lab/`（12 MB）是 CDN 上传暂存，**不入库**；`public/` 是构建产物。

### 1. 页面级清洁

| 检查 | 判定方式 | 处理 |
|---|---|---|
| 未完成占位（TBD／待补／空 section） | `check_migration.py` R12 | 清掉占位或补内容，带占位不得上线 |
| 页面专属 JS/CSS 散落成独立文件 | 单页引用且 < 10 KB | 内嵌到该页 `page_content` **末尾**，并用 `document.addEventListener('DOMContentLoaded', …)` 包裹 |
| 同一页面重复引入同一资源 | 扫 `{% block styles %}` / `{% block scripts %}` | 去重；`utils.js` 必须最前 |
| 多段内联块逻辑重叠 | 逐页比对 | 合并进共享文件，或删掉后加载的那份 |

> **内联的坑（2026-10-20 实测）**：`{% block scripts %}` 渲染在 layout 的 `<head>`，原脚本靠 `defer` 在解析后执行；直接内联会提前到 head 解析期——`model-game.js` 拿不到 DOM 直接 return、`members.js` 报「缺少依赖 utils.js」。必须移到 body 末尾 + `DOMContentLoaded` 包裹。

### 2. 组件级清洁（资源瘦身）

- **孤儿扫描**：仓库根执行 `python .codebuddy/skills/igem-wiki-migration-guard/scripts/audit_flask_assets.py`。自有 CSS/JS 孤儿必须为 0；官方模板资源即使 0 引用也保留。
- **数据瘦身（本项目最大头）**：`static/data` 的 PDB 由 `game-docking.json` / `model-docking.json` 的 `structureBase + file` **动态拼路径**加载，按文件名 grep 会全部误判为未引用。正确判定是读 JSON 里的 `clusters[].models[].file`、`antibodies[].file`、`antigens[].processed`，只保留这些文件，其余归档。
  2026-10-20 已归档 283 个 / 32.5 MB 到 `对话归档/2026-10/2026-10-20-unreachable-structures/`：`complexes/rigid/` 全量（83）、`antigens/native/` 全量（2）、`complexes/flex/` 中非 `*_c1_m1` 的 195 个、`antigens/processed` 多余 1 个。
- **跨文件重复 CSS**：先按加载顺序判断保留谁——layout 顺序是 `navigation → index → mobile → components → 页面样式`；human-practices 页是 `integrated-human-practices → hp-head-extra`（后者覆盖前者）。
  **自动删重复规则风险高**：用文本删除时容易连相邻规则的 `}` 一起切掉（2026-10-20 实测：`navigation.css` 掉 3 个 `}`、`integrated-human-practices.css` 掉 4 个，导致整页样式失效，已回滚）。要处理必须逐条人工确认，并校验 `{` / `}` 计数相等后再构建。
- **合并小 CSS**：单文件 < 1 KB 且只被 layout 引用 → 并入 `index.css` 顶部（`base.css` 已于 2026-10-20 并入）。

### 3. 注释级清洁

- 推送文件里**不得**出现日志句：日期、「本轮／原先／迁移版」、「实测／用户要求」、本地路径（`对话归档/…`）、内部脚本名、`文件:行号`。
- **保留**：功能说明、参数说明、许可头（`@license` / `Copyright`）、第三方库全部注释。
- 工具：`python 对话归档/temporary-tools/comment_audit_flask_full.py --scan|--fix`（幂等）。改完再扫一遍必须为 0 条。

### 4. 引用级清洁（防 CI 404）

- 删任何文件前：`url_for('static', filename=…)` 与字面 `static/…` **两路都要 grep**（红线 R-C）。
- 删完立刻 `flask freeze` + `check_migration.py`，确认无新增 FAIL。
- **本工程 URL 带 `/szpu-china/` 前缀**：`check_migration.py` 的 R14 与 `find_broken_links.py` 按 `public/` 根解析，会把这些引用**全部误报**成断链（实测 336／21 条，真实为 0）。真实判定用前缀感知脚本 `对话归档/temporary-tools/check_links_prefixed.py`（2026-10-20：1317 个引用 / 真实断链 0）。
- **删除清单要自己再分一遍**：`gen_manual_upload_list.py` 的「要删除」只认 4 个故意不建的页面，本地删掉/内嵌掉的资产会被归进「官方独有」，必须人工区分「我们删的（要同步删）」与「官方模板自带的（不能删）」。判定口径：`git ls-tree -r --name-only igem/main` 减去本地文件，再逐个 grep 引用；0 引用才可删。

### 5. 顺序不可颠倒

清洁整理 → `flask freeze` → `check_migration.py`（无新增 FAIL）→ `gen_manual_upload_list.py`（**全树差集，禁止手写清单**）→ CI 就绪度闸 → 分批推送（同页结构+样式+脚本同批）→ 线上复验。

## Team page: member categories and order (parity with root site)

`wiki/pages/members.html` renders entirely from `static/js/pages/members.js`; the single
source of truth for the left strip groups is its `ROLE_ORDER` array, kept identical to the
root static site (root is authoritative — see root `README.md` **§5.15**):

`PI → Adviser → Wet Lab → Dry Lab → WIKI → HP → Art → Designer`

- A member is grouped by the **first** `ROLE_ORDER` entry present in their `roles`; the other
  non-classification roles render as detail/rail tags. Display labels such as `Primary PI` /
  `Secondary PI` therefore sit in `roles` next to the classification role `PI`
  (e.g. `['Primary PI', 'PI']`).
- Empty groups are skipped by the renderer — `Designer` currently has no member, so it shows
  no header.
- Adding a category needs three edits in lockstep: `ROLE_ORDER`, `ROLE_COLORS` in
  `members.js`, and `.group-indicator[data-role="…"]` in `static/css/members.css`.
- This file mirrors the root version with the `https://static.igem.wiki/teams/6373/wiki/image/...`
  prefix, so every new member photo (`webp/<id>.webp`, optionally `webp/<id>_kt.webp`) must be
  uploaded to the iGEM Uploads CDN before it shows on the live site.
- Each member carries the same 7 fields in a fixed order —
  `id → name → roles → directions → bio → photoPosition → photoSize` — plus an optional

  a member's full-bleed background photo (they map to CSS `background-position` /
  `background-size`); the current value for every member is tabulated in root `README.md` §5.15.

- Members whose text is still pending keep `directions: []` and `bio: ''` — no placeholder
  tokens, which must never reach the frozen build.
- Re-runnable structural check (validates field order, group hit, framing fields and that every

  `node 对话归档/temporary-tools/2026-09/2026-09-15-check-members-format.js`.

## Flask 工程操作红线（每次改动前必读）

> 本文件不推送，仅本地协作用。每次修改 `igem2026-flask/` 内任何文件前，先读完本节。

### 1. URL 与冻结产物：无扩展名是硬规定
- 路由统一 `@app.route("/<page>")`（外加 `/` 与显式 `/design`）。Frozen-Flask 写出的产物是 `public/<page>`（**无 .html 扩展名**），由 GitLab Pages 当 `text/html` 提供。
- **绝不要**把链接或路由改成 `/<page>.html`，否则评委按官方标准链接 `2026.igem.wiki/szpu-china/<page>` 访问会 404，相关项可能不予评审。
- 本地预览**必须**用 `flask serve`（或 `python -c "from app import freezer; freezer.run()"`），它会把无扩展名文件正确识别为 html。**不要**用 `python -m http.server` 打开 `public/`——浏览器会把无扩展名文件当 `octet-stream` 直接下载，那不是 bug，是本地服务器 MIME 识别问题。

### 2. Python 文件只有一个：app.py
- 仓库里只应有一个 Python 入口 `app.py`，**不要**新增 `site_nav.py` 之类的本地模块。导航（6 栏目 + 17 子项）已硬编码进 `wiki/menu.html` 与 `wiki/footer.html`，与官方 2026 模板、BNUZH 2025、Manipal 2022 写法一致。
- `app.py` 不 import 任何本地文件；改完路由/生成器直接 `flask freeze` 即可，漏传也不会崩。

### 3. design 页位置
- 源文件：`wiki/pages/design.html`（**平铺**，与官方模板一致；2026-09-29 起不再有子目录）；对外 URL **保持 `/design`**。评委标准链接能直接点开，零风险。

### 4. 推送时禁止改动/删除的文件
- 官方模板自带、本地没有或不该覆盖的文件不要删：`README.md`、`.gitlab-ci.yml`、`dependencies.txt`、`.gitignore`、`LICENSE`、`CLAUDE.md`、`.claude/RESPONSIBLE_AI_USE.md`、`static/bootstrap.min.css`、`static/bootstrap.bundle.min.js`、`static/style.css`、`wiki/pages/inclusivity.html`（官方模板自带，本地无此页）。
