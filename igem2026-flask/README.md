# SZPU-China 2026 Wiki (Frozen-Flask)

This folder is the **official iGEM 2026 wiki source** for `gitlab.igem.org/2026/szpu-china`.
It follows the iGEM-provided `wiki-frozen-flask` template: a Flask app is frozen into a
static site by `flask freeze` and published by GitLab Pages.

## Structure

```
igem2026-flask/
├── app.py                 # Frozen-Flask entry: / -> home.html, /<page> -> pages/<page>.html
├── dependencies.txt       # Flask + Frozen-Flask
├── (migrate_wiki.py)      # one-off migration helper, now in ../对话归档/research-reports/gitlab/
├── static/                # vendored CSS/JS/images (served from iGEM GitLab Pages)
│   ├── bootstrap/         # Bootstrap 5.3.3 vendored locally (no 3rd-party CDN)
│   ├── css/wiki.css       # team base styles
│   └── image/             # all images, referenced as /static/image/...
├── wiki/
│   ├── layout.html        # shared layout: Bootstrap + blocks title/lead/page_content
│   ├── menu.html          # Bootstrap navbar (official 2026 page set)
│   ├── footer.html        # CC BY 4.0 license + visible gitlab.igem.org/2026/szpu-china link
│   └── pages/             # one .html per wiki page (extends layout.html)
└── public/                # BUILD OUTPUT (gitignored) — generated by `flask freeze`
```

## Page set (matches the official iGEM 2026 deliverable structure)


## Compliance notes

- **Rule 1 (hosted on iGEM):** all CSS/JS are vendored under `static/` and served by
  GitLab Pages (iGEM infrastructure). No third-party CDNs (Google Fonts, jsDelivr,
  alicdn, …) are referenced. The only external hosts are `static.igem.org` (favicon,
  an iGEM domain) and allowed outbound links (szpu.edu.cn, bilibili, mailto).
- **Rule 2 (CI build):** GitLab CI runs `flask freeze` on the default branch and publishes
  `public/` via GitLab Pages (see `.gitlab-ci.yml` in the repo root).
- **Rule 3 (predictable URL + footer link):** every page has a clean, predictable URL
  (`/Description`, `/Model`, …) and the footer contains a visible
  `gitlab.igem.org/2026/szpu-china` link plus the CC BY 4.0 license.
- **JS placement:** no `<script>` tags appear inside page templates; all JS is loaded
  once from `layout.html` (Bootstrap bundle, vendored locally).
- **Bootstrap:** the layout uses Bootstrap 5, vendored locally under `static/bootstrap/`.

## Images: iGEM Uploads CDN only (mandatory)

Per the iGEM 2026 rule (and matching `2025/szu-china`), `static/` may contain **only JS and
CSS** — no images. All images are uploaded to the iGEM Uploads CDN and referenced as
`https://static.igem.wiki/2026/szpu-china/image/...`. The repository's `static/image/`
folder has been removed; page references were rewritten to the CDN by `fix_assets.py` (archived under ../对话归档/research-reports/gitlab/).

**To go live:** upload the files from the workspace `static/image/` (keep the `image/`
prefix) via the iGEM upload tool, then delete the local `static/image/` copy. Until
uploaded, local `flask run` preview will show broken images (expected) — the live
GitLab Pages site serves them from the CDN. See `IGEM2026_WIKI_COMPLIANCE.md` for the full
rule set and pre-commit checklist.

## Performance & JS optimization (parity with root static site)

The vendored JS under `static/js/` mirrors the performance optimizations applied to the
root static site — see root `README.md` **§14 性能分析与优化** and **§5.11 搜索子系统**
for the full rationale. The two workspaces are kept in sync on these points:

- **Search index as JSON + `fetch`** — `core/search.js` loads `core/search-index.json` via
  same-origin `fetch()` on first open (no per-page `<script>` injection, no global
  `window.iGEMSearchIndex`). Results render with `document.createElement` + `textContent` +
  a controlled `<mark>` (no `innerHTML`). Rebuild with
  `python tools/search_index_generator.py` **after** `flask freeze` — it scans the
  flat `public/*.html` output (skips `index.html`, the `/` duplicate of `home.html`).
- **Reduced motion** — `core/utils.js` exposes `prefersReducedMotion()`; the
  executive-summary animation (yeast float / typewriter / reveal / smooth scroll) respects it.
- **Lean components** — `components/sidebar-progress.js` and `pages/attributions.js` dropped
  their test/debug code and init `console.log`.
- **HP map clustering** — `components/hp-map.js` groups experts by province into a single
  `.hz-cluster` pin (fewer DOM pins than one-pin-per-expert), with a hover popover listing
  that province's experts; the detail still opens in the existing `#hzModal`. Data source
  remains `static/data/hp-map-data.js` (`window.HPMapExperts`), now carrying `slug` /
  `provinceId` / `provinceName` fields.

Note: the search index generator is pure Python (stdlib `html.parser`), so it runs in the
Python-only GitLab CI image — `.gitlab-ci.yml` invokes `python tools/search_index_generator.py`
right after `flask freeze`. It writes both `static/js/core/search-index.json` (committed
source) and `public/static/js/core/search-index.json` (deployed artifact).
