为什么入库
  站点的部署目标（含后续官方提交工程）要求完全离线可用，不得依赖外部 CDN。
  与 static/js/pdfjs/ 的历史做法不同：pdfjs 走 iGEM 官方 CDN 故不入库，本库无同类
  官方 CDN 可用，且三维视图是本页的核心交互之一，因此随源码入库（单文件 < 1 MB，
  符合 README 第 17.3 节二进制体积预算）。

升级方式
  重新下载同一 URL 覆盖本文件，并同步更新本说明的版本、体积、哈希三行；
  覆盖后必须重新跑一遍页面的三维加载自检（点击载入 → 渲染 → 切换显示模式）。
