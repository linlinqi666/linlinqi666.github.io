# REQ-20260826-002 根站内容同步至 Flask 站（逐页核对，仅补缺口）

- 类型：体验优化 / 内容同步
- 工程：跨工程（根目录 Eleventy 站 → igem2026-flask 官方站）
- 状态：已完成
- 创建：2026-08-26
- 关联进度文档：`Progress/PROG-REQ-20260826-002-root-to-flask-sync.md`

## 1. 用户诉求

将根目录静态站（参考版）的内容同步到 `igem2026-flask` 官方站，约束条件：
1. 首页（index / home）**不同步**。
2. 图片资源**不迁移**，留在原处闲置（Flask 站图片统一走 iGEM CDN `static.igem.wiki/2026/szpu-china/`）。
3. 其余页面尽量对齐。

## 2. 关键发现（影响方案）

逐页比对（17 个页面 + Flask 独有页）后确认：

- 两站正文**已基本对等**；Flask 站（官方提交版）实际是更完整的英文成品版。
- Flask 站 `results.html` 已修复 `results.css` 的 404（改引 `description.css`）。
- 根站多数页面是早期中文草稿（带 `[待补充]` 注释、未引 CDN 图片、Nunjucks 模板外壳），直接覆盖会倒退 Flask 并破坏其构建。
- `experiments`：两站 exp1–exp6 正文逐字相同，唯一差异是 Flask 把 6 个实验收进侧边栏折叠子菜单；根站为平铺锚点。
- HP 页面：Flask `human-practices.html` 是根站 `integrated human-practices.njk` 的**升级迭代版**（多了 modal 专家照片弹窗、时间轴滑块、完整地图 SVG）；`education` 逐字对等；`social-groups` ↔ Flask `inclusivity` 均为占位且逐字相同。**HP 无缺口**。
- `parts`、`social-groups` 双方均为空占位；Flask 独有页（`home`/`alternative-platform`/`entrepreneurship`/`measurement`/`sustainability`）结构占位或已有内容，根站无对应源。

## 3. 方案（经用户确认）

方向：**仅补 Flask 缺口**，不直接覆盖。

唯一改动：将 Flask `wiki/pages/experiments.html` 侧边栏的"实验模块"折叠子菜单展开为 6 个平铺 `level1` 锚点项，与根站导航结构一致（正文不变）。

| 页面 | 决策 |
|---|---|
| experiments | 侧边栏折叠 → 平铺（已执行） |
| 其余 project/dry-lab/wet-lab/human-practices/team | Flask 已对等或更完整，保持不变 |
| parts / social-groups(inclusivity) | 双方占位，不变 |
| home / 独有页 | 不同步范围外，不变 |

## 4. 写入入口与验收

- 写入入口：`igem2026-flask/wiki/pages/experiments.html`（侧边栏 `<ul class="description-nav">` 内）。
- 验收：Flask 构建通过；`flask freeze` 生成 `public/experiments.html`；HTTP 下侧边栏 6 个实验锚点可见可跳转。
- 图片：本次无图片迁移。

## 5. 范围外 / 不做项

- 不覆盖 Flask 任何已对等或更完整的页面。
- 不迁移图片资源（按用户要求闲置）。
- 不同步首页。

## 6. 风险

- 若未来根站对某一页有实质性内容更新（非草稿），需重新评估是否补同步；当前根站内容不构成领先。
