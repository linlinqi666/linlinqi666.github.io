# REQ-20260826-001：根站 JavaScript 插件治理（第一阶段）

- **类型**：体验优化 / 性能与安全加固
- **工程**：根站（Eleventy）
- **状态**：阶段 3 进行中
- **创建日期**：2026-08-26
- **依据**：`对话归档/research-reports/2026-08-26-static-js-plugin-audit.md`

## 总目标

在不引入第三方运行时插件、不改变现有页面视觉与内容的前提下，逐步治理根站 JavaScript 的加载、性能、兼容性、安全性与可维护性。

## 已完成阶段

### 阶段 1：搜索索引与安全渲染

- 搜索索引改为按需加载的同源 JSON。
- 搜索结果改用 DOM API 和 `textContent` 渲染。
- 查询长度限制为 80 个字符。
- 构建产物不再生成旧 `search-index.js`。

### 阶段 2：滚动与动画偏好治理

- `iGEMUtils.prefersReducedMotion()` 已加入公共工具层。
- 首页浮动、逐字输入、揭示动画和 CTA 滚动已支持 reduced-motion。
- 页面进度脚本已复用公共 `rafThrottle`。

## 阶段 3：HP 轮播与专家地图

### 本阶段实施

- `hp-flat-carousel.js`：增加 Pointer Events 触摸/鼠标滑动；补充 Home/End 键盘导航；改善 `inert` 不可用时的焦点回退；使用 DOM API 创建轮播卡片；按 reduced-motion 控制轮播过渡。
- `hp-map.js`：使用 DOM API 创建专家集合弹层和图钉文本；使用 `replaceChildren()` 清理图钉；避免动态数据进入 `innerHTML`；保留现有专家内容、筛选逻辑和视觉结构。
- HP 模板：补充轮播的基本 ARIA 语义，不改变现有 CSS 类名和页面结构层级。
- 执行 JS 语法检查、全量构建和 HTTP/浏览器验证。

### 不在本阶段实施

- 不引入 `Embla`、`GSAP`、`ECharts`、`Leaflet`、`MiniSearch` 或其他第三方插件。
- 不拆分或重写 `hp-map.js` 中的专家事实数据，不修改专家文案、图片、模块编号或核验状态。
- 不改变地图坐标、筛选分类、弹层布局、轮播顺序、页面 URL 或现有视觉节奏（reduced-motion 除外）。
- 不处理首页缺失 SVG、favicon 等已记录的独立资源问题。
- 不增加服务端接口、持久化数据或分析追踪。

## 阶段 4：构建与加载治理

### 本阶段实施

- HP 页面以可复用 `partials/hp-map-script.njk` 加载地图组件，消除页面内联脚本路径分叉。
- GitHub Pages 工作流在上传前执行 `npm ci` 和 `npm run build:all`，确保 Eleventy 页面和搜索索引在 CI 中生成。
- 执行模板构建、工作流 YAML 解析与 HTTP 页面资源核验。

### 本阶段不实施

- 不将 Eleventy 输出从仓库根目录迁移至 `_site/`；这会改变根站产物与部署边界，需独立迁移需求和回滚方案。
- 不固定 Actions 到 commit SHA；保留现有主版本标签，待发布链独立安全审查后统一处理。
- 不为现有内联样式/其他工程新增 CSP；严格 CSP 需要先完成内联资源迁移或 nonce/hash 设计。
- 不处理 `igem2026-flask/` 的独立地图实现与发布链。

## 安全与兼容性约束

- 专家资料和轮播资料均视为不可信文本，动态内容使用 `textContent`。
- 触摸滑动只在水平位移超过阈值后切换，不阻断垂直页面滚动。
- `inert` 不可用时，通过 `aria-hidden` 和后代焦点 `tabindex` 回退；激活时恢复原始 tabindex。
- 轮播在 `prefers-reduced-motion: reduce` 下不使用过渡等待。
- 旧浏览器不支持 Pointer Events 时保留按钮、键盘和点击操作。

## 验收标准

1. `node --check` 通过 `hp-flat-carousel.js` 与 `hp-map.js`。
2. `npm run build:all` 成功，页面数量和搜索索引不回退。
3. 搜索模块仍无旧 `search-index.js` / `iGEMSearchIndex` 引用。
4. 轮播按钮、卡片点击、左右/Home/End 键、水平滑动均可切换；垂直滚动不被阻断。
5. 无 `inert` 时非活动详情内容不可通过 Tab 获取焦点，切换后活动内容可访问。
6. 地图专家弹层与图钉文本不通过 `innerHTML` 注入。
7. 现有 HP 专家内容、图片路径、分类筛选和页面结构保持不变。

## 受影响模块

| 写入入口 | 读取方 / 刷新路径 | 风险控制 |
|---|---|---|
| `hp-flat-carousel.js` | HP 页面 front matter 加载 | 保持 `window.HPFlatCarousel` API 与 CSS 类名 |
| `hp-map.js` | HP 概述区地图 | 只改动态节点创建和键盘/焦点回退 |
| `integrated human-practices.njk` | Eleventy 生成 HP HTML | 只补 ARIA 属性，不改专家事实内容 |
