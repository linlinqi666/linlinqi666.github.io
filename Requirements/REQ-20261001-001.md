## 3. 实现方案

**状态机**（类挂在 `.art-stage--statistics`）：

```
无 JS / reduced-motion / 无 IO / 无 WAAPI  →  不接管（完整静态布局）
DOM 就绪                → .js-reveal-armed（ELISA/qPCR opacity 0、虚线弧 clip 归零、CGIS 可点）
滑入视口（IO 0.45）      → .in-view（标题逐词下落 + 「Click here」出现）
点击 / 回车 / 空格       → .revealed（弧 → ELISA → qPCR 依次展开；提示淡出移除）
时间轴结束              → .revealed-done（去 armed、清内联 transform、取消 WAAPI、撤 a11y 属性）
```

**几何在运行时量测**（同一套代码覆盖桌面与 ≤768px 两套定位数值）：

- 取 CGIS 与两圆的 `getBoundingClientRect`；隐藏态位移 `d = CGIS中心 − 目标中心`，缩放 `s = min(CGIS宽/目标宽, CGIS高/目标高) × 0.86`。
- 展开用 WAAPI 三关键帧（0 → 0.55 → 1）：中段控制点 = 把 `d` 绕 CGIS 同旋向偏 **22°**、缩到 0.46 倍，形成「绕轨道」弧线；两个圆按目标左右各偏一侧，视觉上呈对称外旋。
- 最终帧是 `translate(0,0) scale(1)`，收尾时清内联样式即回到 CSS 布局——**最终态与改动前逐像素一致**。

**虚线弧「画出」**：不重绘 SVG，直接对现有 webp（`art--statistics-arc`）做 `clip-path: polygon()` 扇形擦除（从 CGIS 端向左上展开，`0% 100%` 角点 → 覆盖全盒），零对齐成本、零素材改动。

**时间轴**（`static/js/pages/statistics-reveal.js` 顶部 `T` 常量，可整体调速）：弧 0→460ms；ELISA 延迟 280ms、飞行 950ms；qPCR 延迟 560ms、飞行 950ms；提示延迟 780ms 出现（等标题落定）。

## 4. 关键防呆（本轮踩点与红线）

- **半径/层级红线**：隐藏态同时满足两条——① `opacity: 0`（脚本加类前不隐藏，加类后彻底不可见）；② 内联 `transform: scale(0.86×)` 把 ELISA（14.4%）/qPCR 圆盒缩到 **严格小于** CGIS（13%）圆盒并同心，实测桌面 143×143 落在 166×166 内、移动 69×69 落在 81×81 内 → 即使不依赖 CGIS 遮挡也不会露边。z 序上 CGIS 仍在 DOM 后面（后绘制），符合「ELISA/qPCR 层级在 CGIS 之下」。
- **量测时机**：`mobile.css` 全局 `img { content-visibility: auto }` 会让**视口外**图片拿到 0 高度矩形。故量测放在 IntersectionObserver 回调里、并逐帧重试（上限 30 帧）；仍失败则 `disarm()` 放弃隐藏态并恢复完整布局，避免「圆永久不可见」。
- **无 JS 降级**：隐藏/裁切只由 JS 添加的类触发，默认 CSS 不做任何隐藏；`prefers-reduced-motion: reduce` / 无 IO / 无 WAAPI 直接不接管。
- **降级按钮语义**：`role="button"` / `tabindex` / `aria-label` 只在 armed 期间存在，收尾时移除；点击后 `pointer-events` 回归 `none`。
- **构建注记（修正上轮结论）**：`npm run build` 本身正常，问题是 **PowerShell 管道**（`npm run build | Out-String | Select-Object`）提前关闭管道导致构建被中断、mtime 不变。可靠做法：`npx eleventy *> "$env:TEMP\e11ty.log"` 或直接 `npx @11ty/eleventy` 并核对产物 mtime。

## 8. 2026-10-01 追加 1：展开到位后「消失闪动」根因修复 + 标题改为左上对齐（用户反馈）

### 8.1 闪动（先诊断后修）

**用户观察**：动画做完后 ELISA 与 qPCR 会「消失闪动一下」。

**逐帧采样定位**（点击后 1.9s 内每帧记录 `opacity` + 圆心位置，`requestAnimationFrame` 循环）：

| 时刻 | ELISA | qPCR |
|---|---|---|
| 到位 | t≈1204ms `1@275,204` | t≈986ms `1` |
| **回落** | **t≈1259ms → `0@124,385`（隐藏态），持续到 1604ms** | **t≈1551ms → `0`** |
| 收尾后 | t≈1623ms 起 `1@275,204` | `1` |

**根因**：`flyCircle()` 的 WAAPI 用了 `fill: 'backwards'`——它只在**延迟期内**保持首帧，动画一结束效果即失效，元素立刻回落到两个仍未清除的隐藏态：① `applyHiddenState()` 写入的内联 `transform: translate(d,dy) scale(s)`；② `.js-reveal-armed` 的 `opacity: 0`（`finish()` 在 1600ms 才移除）。于是「到位 → 缩回 CGIS 身后并透明 → 收尾时又弹回」= 肉眼看到的闪一下（ELISA 约 345ms，qPCR 约 95ms）。

**修复**：`fill: 'backwards'` → **`fill: 'both'`**（延迟期保持首帧 + 结束后保持末帧），末帧 = `translate(0,0) scale(1) opacity 1`，一直保持到 `finish()` 在同一帧内「去 armed 类 + 清内联 transform + cancel 动画」，前后状态完全等价 → 无跳变。

**回归验证**：同法逐帧采样 311 帧（桌面 1280×720），判定 `t>1300ms 后 ELISA 恒为 opacity 1`、`t>1000ms 后 qPCR 恒为 1` → **异常帧 0**；移动端 390×844 复测 308 帧，ELISA 从 1306ms 起恒为 `1@67,270`，无回落。截图：`对话归档/screenshots/2026-10-01-statistics-flicker-fixed-desktop.png`。

**教训（可复用）**：凡「内联写入隐藏态 transform + 类控制 opacity」的 WAAPI 逐段动画，**必须用 `fill: both`（或 `forwards`）**，否则动画结束到收尾之间存在「回落到隐藏态」的可见空窗。
