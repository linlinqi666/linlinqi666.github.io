# REQ-20261005-001 首页 statistics 三方法信息条二段动画 + 首页离屏动画停表

## 需求

1. **二段动画（statistics 屏）**：三圆「CGIS 揭示」展开完毕后，三个圆圈可各自触发第二段动画——鼠标移入后展开蓝底白字信息条，介绍 qPCR / ELISA / CGIS 三种检测方式的优势与劣势；移出鼠标蓝条收回。硬性时序约束：三圆展开完毕之前蓝条不可见、不可触发。
2. **内容真实性**：信息条文案以用户提供的《首页逻辑.docx》为基础，需外部信息采集确证。
3. **性能优化**：第二屏（甲流负担计数）与轮播优点屏（project-intro 药丸）滚动卡顿。
4. 完成后更新上传清单。

## 实现

- `src/index.njk`：statistics 屏加 3 个 `.method-info` 信息条（qPCR/ELISA/CGIS，各含 1 优势 + 1 劣势，英文与首页现有文案语言一致）；登记 `home-idle-motion.js`。
- `static/css/index.css`：`.method-info` 蓝底白字条（clip-path 擦除展开，只动 clip-path/opacity/visibility）；`.js-methods-armed` 收起态；`.is-open` 展开态；armed 圆圈开放 pointer-events；桌面/移动定位；文末新增「首页离屏动画停表」段。
- `static/js/pages/statistics-reveal.js`：setup 即加 `js-methods-armed`（揭示前不可见）；`finish()` 才 `bindMethodBars()`（hover/focus 开、blur/mouseleave 收、触屏点按开/关，`revealedDone` 闸门双保险）；`disarm()` 解除接管。
- `static/js/pages/influenza-burden.js`：秒节拍光点（infinite WAAPI）随 rAF 停表/标签页隐藏/离屏一并 pause，复工 play。
- `static/js/pages/home-idle-motion.js`（新）：IO 观察各 `.presentation-section`，ratio=0（含相邻屏边界相切停稳态）打 `data-offscreen`，CSS 统一 `animation-play-state: paused`；ratio>0 恢复。
- 降级：无 JS / reduced-motion → 信息条静态可见、动画全量照常（隐藏态只由 JS 加类）。

## 内容确证

《首页逻辑.docx》Part 1：qPCR/ELISA 高灵敏高准确但依赖设备实验室与专业人员；CGIS（胶体金免疫层析）可现场快检。外部确证（CDC《Overview of Influenza Testing Methods》、CDC RIDT Guidance、MDPI 2025 综述）：qPCR 分子法为推荐参考方法；ELISA 检测病毒蛋白而非核酸（docx 笔误，文案已修正）；胶体金快速检测主要短板是**灵敏度有限（易假阴性）**而非假阳性——docx「假阳性高」按 CDC 口径修正为「灵敏度有限、结果不确定性高」。
