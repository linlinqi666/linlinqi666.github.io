## 4. 失败、取消、回滚与安全边界

| 情形 | 行为 |
|---|---|
| 三维库加载失败 | 按钮恢复可用、面板给出可读文案，控制台只告警一次（不重试、不刷屏） |
| 结构文件 404 | 同上，提示「结构文件未能载入」 |
| 内联数据缺失 | 演示区显示降级提示，页面正文表格仍完整可读（正文不依赖脚本） |
| JS 未执行 | 卡牌区为空、结果区为空，但正文与表格完全可读；无 JS 时页面不报错 |
| 回滚 | 单页改动：还原 `src/dry-lab/model.njk` 与 `static/css/model.css`、删除新增的 `static/js/pages/model-game.js`、`static/data/dry-lab/model/`、`static/js/3dmol/`、`static/image/dry-lab/model/`，并从 `sectionIdPrefixes` 移除 `model-` |
| 安全 | 无用户输入、无持久化、无第三方请求；结构文件与三维库均为本地资源（零 CDN）；DOI/链接一律不臆造 |
