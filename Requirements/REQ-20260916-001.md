# REQ-20260916-001：成员页响应式重构 + 全屏引导封面（根站 + flask 同步）

- **类型**：功能 + 体验优化
- **工程**：跨工程（根站权威源 → `igem2026-flask` 镜像）
- **状态**：已完成（flask 侧封面图待上传 CDN）
- **创建日期**：2026-09-16
- **依据**：用户 2026-09-16 指令——①「成员页响应式做得特别差，优先改进」；②「进入成员页应先全屏展示整队照片 `total.jpg`，点击再进入成员页」。

## 总目标

1. 用多断点实测定位并修掉成员页的响应式缺陷（首屏空白、列表被裁、嵌套滚动、照片被挤、中段桌面拥挤）。
2. 新增全屏引导封面：进入成员页先看整队照片，点击/键进入；桌面与手机都能看到照片，且有完整降级路径。

## 改造前的实测问题（11 个断点基线）

| 断点 | 现象 | 根因 |
|---|---|---|
| 375 / 414 / 768 / 834 / 1024 | 条带顶部 220–228px；**无任何成员内容**（详情卡隐藏）；手机无照片；375 与 1024 展开后被裁 | `main` 已有 100px 顶栏留白，条带又加 100px；初始化仅在 >1024 时选中成员；≤768 直接隐藏背景层；展开上限固定 1200px + `overflow:hidden` |
| 1180 / 1280 | 照片可视带宽仅 410 / 510px（条带 390 + 信息条 380 全固定） | 宽度写死，无流式收缩 |
| 全部断点 | 条带内部独立滚动条（嵌套滚动） | 堆叠布局未取消 `max-height: calc(100vh-100px)` + `overflow-y:auto` |
| 桌面 | 页面高度比内容多 100px | `min-height: 100vh` 未扣除顶栏 |

## 改造内容

### 1. 布局矩阵（断点 1100，两侧必须一致）

| 视口 | 布局 |
|---|---|
| ≥1100px | 桌面分栏：条带 `clamp(300px,30vw,390px)` + 全幅人像 + 信息条 `clamp(272px,24vw,380px)` |
| ≤1099px | 堆叠：人像改为顶部 hero（`clamp(200px,30vh,340px)`，底部渐隐）+ 条带折叠为切换器 + 信息条收起、简介入详情卡 |
| ≤640px | hero 收窄至 `clamp(172px,26vh,260px)`，标题/正文降一档 |

### 2. 行为改造

| 项 | 改造后 |
|---|---|
| 默认选中 | **所有断点**都选中首位成员（桌面=背景+信息条；堆叠=hero+详情卡） |
| 展开高度 | `scrollHeight` 实测写入 `--strip-groups-max`；组内折叠后事件委托重测；视口切换清理；CSS 仅留 2400px 兜底 |
| 条带滚动 | 堆叠布局取消条带自身滚动，随页面滚动 |
| 选中反馈 | 堆叠布局下自动收起列表，并在详情卡完全移出视口时平滑带入 |
| 动效降载 | 新增 `prefers-reduced-motion` 区块（停用过渡；`.detail-tag` 恢复 `opacity:1`，否则关闭动画后标签不可见） |
| 键盘焦点 | 成员条/组标题/切换按钮统一品牌色 `:focus-visible`；程序化聚焦不再出现浏览器默认黑框 |

### 3. 全屏引导封面

| 项 | 说明 |
|---|---|
| 素材 | `total.jpg` 1919×1279 / 578 KB → `webp/total.webp` 1919×1279 / 163.5 KB + `webp/total-960.webp` 960×640 / 72.2 KB（`srcset`） |
| 状态机 | `<html>`: `members-intro-armed` → `members-intro-ready` → `members-intro-finished` |
| 交互 | 点击任意处 / Enter / Space / Esc / 按钮；淡出后解锁滚动、恢复 `inert`、焦点交给条带容器 |
| 降级 | 无 JS 不 arm（封面默认 `display:none`）；控制器失败时 arm 内 8s 看门狗强制收尾 |
| 展示频率 | 默认每次进入都显示；`ONCE_PER_SESSION = true` 可改为每会话一次 |
| 移动端取景 | 竖屏 `object-fit: contain`（整队完整）+ 同图模糊衬底；桌面 `cover` + `object-position: center 28%`（保头部） |
| 无障碍 | `role="dialog" aria-modal="true"`；页面内容 `inert`+`aria-hidden`；新增页面唯一 `h1`（`.members-sr-only`，此前该页无 h1） |

- 其他页面：新组件仅由成员页加载；`members-sr-only` 为页面级工具类，未改全局样式。
- 归因页：本轮未动（其成员卡使用独立 `data-role` 体系）。
